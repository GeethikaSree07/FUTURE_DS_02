# Customer Retention & Churn Analysis

## Project Overview

This project analyzes customer churn behavior using the Telco Customer Churn dataset. The goal is to identify factors influencing customer retention and provide actionable business recommendations.

## Problem Statement

Businesses lose revenue when customers leave their services. This project aims to understand:

- Why customers churn
- Which customer groups are more likely to leave
- Customer lifetime behavior
- Retention strategies to reduce churn

## Dataset

Dataset: Telco Customer Churn Dataset

Rows: 7043  
Columns: 21

## Tools Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed

- Data Cleaning
- Churn Rate Analysis
- Gender vs Churn
- Contract Type Analysis
- Monthly Charges Analysis
- Tenure Analysis
- Internet Service Analysis
- Correlation Heatmap

## Key Findings

- More customers stayed than churned
- Month-to-month customers showed highest churn
- Customers with high monthly charges tend to leave
- Fiber optic users showed higher churn
- New users displayed stronger churn patterns

## Recommendations

- Promote yearly subscription plans
- Improve onboarding experience
- Offer loyalty rewards
- Focus on retaining new customers
- Create personalized retention campaigns
